# Parameter values and outputs from Band's Collision Risk spreadsheet, example nr. 2

A list object comprising parameter values and outputs from Band's worked
example for testing the consistency of package functions with the
original model and its implementation.

## Usage

``` r
band_spreadsheet_dt_2
```

## Format

A list object containing:

- flight_speed:

  Bird flight speed, in m/s

- rotor_radius:

  rotor radius, in meters
